TỔNG QUAN

Collections trong AXQ Variable System

1. Primitive / Color
Mode: Value
  • white, black
  • greyscale/100–900
  • brand (teal, green, orange, pink, purple, yellow, grey)
  • info/100–900
  • success/100–900
  • warning/100–900
  • error/100–900
1. Primitive / Spacing
Mode: Value
  • space/0, 2, 4, 6, 8, 10
  • space/12, 16, 20, 24
  • space/32, 40, 48, 56
  • space/64, 80, 96, 128
1. Primitive / Radius
Mode: Value
  • radius/none → 0
  • radius/xs → 2
  • radius/sm → 4
  • radius/md → 8
  • radius/lg → 12
  • radius/xl → 16
  • radius/2xl → 24
  • radius/3xl → 32
  • radius/full → 9999
1. Primitive / Font Size
Mode: Value
  • fontSize/10, 12, 14, 16
  • fontSize/20, 24, 34
  • fontSize/48, 60, 96
2. Semantic / Color
Mode: Light
  • bg/ (primary, secondary, tertiary, inverse, brand, disabled)
  • surface/ (default, raised, overlay, sunken)
  • text/ (primary, secondary, tertiary, disabled, inverse, brand, link, on-color)
  • icon/ (primary, secondary, disabled, inverse, brand)
  • border/ (default, strong, subtle, disabled, focus)
  • status/ (info/success/warning/error × bg, default, subtle, text)
  • accent/ (teal, green, orange, pink, purple, yellow)
2. Semantic / Spacing, Radius, FontSize
Mode: Default
  • spacing/ (none, 3xs, 2xs, xs, sm, md, lg, xl, 2xl, 3xl, 4xl)
  • inset/ (xs, sm, md, lg, xl, 2xl)
  • gap/ (xs, sm, md, lg, xl)
  • radius/ (none, button, input, card, modal, chip, avatar, badge)
  • type/ (overline, caption, body-sm, body, h6, h5, h4, h3, h2, h1)

QUY TRÌNH

Thiết lập Variable System trong AXQ Design File

1
Tạo 7 Collections

Mở bảng Variables → Tạo: AXQ / Primitive / Color, AXQ / Primitive / Spacing, AXQ / Primitive / Radius, AXQ / Primitive / Font Size, AXQ / Semantic / Color (mode: Light), AXQ / Semantic / Spacing+Radius+FontSize, AXQ / Component.

2
Khai báo Primitive trước

Nhập toàn bộ giá trị thô: màu hex, số px. Không trỏ sang collection khác ở bước này.

3
Tạo Semantic → Alias từ Primitive

Chuột phải vào ô Value → chọn "Apply alias" → tìm token Primitive tương ứng. Ví dụ: text/primary alias tới greyscale/900.

4
Tạo Component tokens → Alias từ Semantic

Mỗi component token trỏ tới Semantic (không trỏ thẳng về Primitive). Đảm bảo chuỗi: Component → Semantic → Primitive.

5
Gán Variable vào Master Components

Chọn layer cần gán → dùng bảng Fill/Stroke/Text/Corner Radius → click biểu tượng Variable → chọn token Component tương ứng.

6
Thêm mode Dark (tương lai)

Chỉ cần thêm mode "Dark" vào collection AXQ / Semantic / Color và override các giá trị màu. Component tokens tự cập nhật vì đã alias qua Semantic.

💡 Lưu ý naming convention AXQ: Tất cả collection đặt prefix AXQ / để phân biệt với các library khác trong cùng file. Ví dụ: AXQ / Primitive / Color, AXQ / Semantic / Color, AXQ / Component / Button.
