## Cộng tác

- Dùng GitHub Issues để ghi nhận yêu cầu, lỗi, nghiên cứu và công việc hạ tầng.
- Dùng Pull Request để review thay đổi và lưu lại cách kiểm chứng.
- Không đưa credentials, dữ liệu cá nhân hoặc nội dung không có quyền sử dụng vào repo.
