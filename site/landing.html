Features
Everything you need for a production-ready FinTech UI kit

iOS First

Designed for iOS 375×812 · 8px grid system · iPhone Dynamic Island compatible · Neubrutal style

3-Layer Token System

Primitive → Semantic → Component. Full Figma Variable export, CSS Custom Properties, Dark Mode overrides.

6000+ Icons

Linear, Bold, Outline, Broken, Bulk, Two-tone. All icons tokenized with size + color primitives.

Work Sans Typography

H1–H6, Body, Caption, Overline. Google Font included. Full token scale from 10px to 96px.

201 Components

Navigation, Inputs, Cards, Buttons, Charts, Crypto-specific, eKYC, Modals, and more. 15 groups documented.

Fully Customizable

All design tokens bound to Figma Variables. Swap any primitive and semantic tokens cascade automatically.
