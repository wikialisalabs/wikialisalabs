# GitHub Achievements

GitHub trao achievement để ghi nhận hoạt động và sự cộng tác trên nền tảng. Một số huy hiệu phổ biến:

| Achievement | Cách đạt được |
| --- | --- |
| Pull Shark | Có pull request được merge vào repository. |
| Quickdraw | Tạo issue hoặc pull request rồi đóng rất nhanh sau khi repository được tạo. |
| Galaxy Brain | Câu trả lời trong GitHub Discussions được đánh dấu hữu ích hoặc được chấp nhận. |
| Starstruck | Repository nhận được nhiều lượt star. |
| Pair Extraordinaire | Cộng tác với một người khác trong pull request. |
| Public Sponsor | Công khai tài trợ cho cá nhân hoặc tổ chức đủ điều kiện qua GitHub Sponsors. |
| Arctic Code Vault Contributor | Huy hiệu lịch sử dành cho người đóng góp vào repository công khai được lưu trong bản chụp Arctic Code Vault. |

Một số achievement có nhiều cấp độ, được biểu thị bằng các tên như Mars, Saturn và các cấp cao hơn. Advent of Code là sự kiện cộng đồng, không phải tên một achievement GitHub; việc tham gia không tự động cấp huy hiệu trên hồ sơ.

## Xem achievements và thống kê

GitHub hiện không cung cấp ảnh nhúng chính thức riêng cho achievements hoặc thống kê hồ sơ. Để không dùng dịch vụ bên thứ ba, phần này hiển thị avatar chính thức và liên kết tới hồ sơ GitHub để xem achievements cùng thống kê trực tiếp.
